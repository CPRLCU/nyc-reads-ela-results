# NYC Reads: ELA Results Explorer

An interactive view of New York State ELA results for grades 3 to 8 in New York City
Public Schools, 2018 to 2026, built by the Center for Public Research and Leadership.

**The live site is `index.html`.** It is one self-contained file: all data, charts and
images are inside it. It needs no server, no database and no build step to work. Opening
it from a web host, or double-clicking it on a laptop, both give the same working tool.

## If you only want to publish it

Upload this folder to GitHub and turn on GitHub Pages, pointing at the repository root.
`index.html` is then served automatically. The step-by-step guide that accompanied this
handover covers it. Nothing else in this folder has to be touched.

## If you need to change the data later

The published file is generated, not hand-edited. Two scripts rebuild it:

    python3 scripts/extract.py    # reads the source workbooks, writes data/payload.json
    python3 scripts/build.py      # writes NYC_Reads_ELA_Dashboard.html
    cp NYC_Reads_ELA_Dashboard.html index.html

Both need Python 3 and `openpyxl` (`pip3 install openpyxl`). Running them on this folder
unchanged reproduces the current `index.html` byte for byte, which is the check that the
handover is complete.

Edit `src/template.html` for page structure and wording, `src/app.js` for charts and
calculations. Do not edit `index.html` directly: the next rebuild overwrites it.

## What the data is

| Path | What it holds |
|---|---|
| `data/citywide-ela-results-public.xlsx` | NYCPS citywide ELA results, 2018 to 2026 |
| `data/borough-ela-results-public.xlsx` | the same by borough |
| `data/district-ela-results-public.xlsx` | the same by community school district |
| `data/nysed/ref20NN.xlsx` | NYSED test refusal rates by district, 2022 to 2025 |
| `data/vendors_sy2025_26.json` | adopted curriculum by district, school year 2025-26 |
| `data/payload.json` | generated by `extract.py`; everything above, compacted |

The NYCPS workbooks are the public files published on the NYCPS InfoHub, file date
3 August 2026. The refusal workbooks are published by NYSED on data.nysed.gov.

**Professional learning provider assignments are deliberately not in this folder.** The
curriculum each district adopted is included and visible in the tool. The JESP each
district worked with is withheld, and the provider fields in
`data/vendors_sy2025_26.json` are null for that reason. `scripts/build.py` checks on
every build that no provider name has reached the published file and refuses to write it
if one has. That check names the providers it looks for, which is the only place any
provider name appears here; no district is linked to one.

## Checking it

Four scripts re-read the source workbooks independently and compare against what the
page actually displays. Together they check 58,846 values.

    python3 scripts/audit_engine.py      # every aggregation, 40,698 combinations
    python3 scripts/audit_refusals.py    # the participation page against NYSED
    python3 scripts/audit_render.py      # 10,832 values read back off the page
    python3 scripts/audit_pass2.py       # charts and tables the first pass misses

The first two run on their own. The last two compare against captures taken from a
running browser, so they need those captures refreshed after a change; `audit/states.json`
and `audit/states2.json` record exactly which views to capture.

## Things that will catch you out

These are properties of the source data, not bugs, and the tool already handles them.
They matter if you ever extend it.

1. **Percentages are derived from counts, never averaged.** Averaging district
   percentages gives the wrong answer because districts differ in size.
2. **2023 is a break, not a step.** NYSED realigned the test and rescaled the scores that
   year, so 2022 and earlier are never differenced against 2023 and later.
3. **The citywide, borough and district files do not reconcile**, and the way they fail
   to reconcile changed in 2025. Each level is read only from its own file.
4. **Suppression hides more than small groups.** Where one group is too small to publish,
   NYSED also withholds the next smallest so it cannot be recovered by subtraction. A
   suppressed cell is never read as zero and no line is drawn across one.
5. **Participation stops at 2025.** NYSED had not published 2026 refusal data at the time
   of this handover and expected to release it in early November 2026.
